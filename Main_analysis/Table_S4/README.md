This folder contains the script `core_set_T_neg_pfam_enrichment.R` to perform an enrichment of PFAMs of the core set of unigenes negatively correlated to temperature across phytoplankton groups.

run `Rscript core_set_T_neg_pfam_enrichment.R groups3`, output: `pfam_enrichment_core_set_T_neg_groups3.rds`
